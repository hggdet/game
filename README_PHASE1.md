# إشارة أخيرة — Phase 1

تنفيذ Phase 1 مهيأ بـ SwiftUI وSpriteKit ويستهدف iOS 17 أو أحدث. يحتوي على غرفة بسيطة ذات جدران، حركة لمس بثلاث سرعات، نظام ضوضاء يتغير بحسب السطح، وDeath Angel بأربع حالات: دورية، تحقيق، اندفاع، وبحث. Death Angel أعمى في هذه المرحلة ولا يتفاعل إلا مع أحداث الضوضاء.

## التحكم

- حرّك العصا الافتراضية اليسرى برفق للتسلل بصمت؛ ادفعها بقوة للمشي وإصدار خطوات مسموعة.
- اضغط مطولاً على زر الركض أو انقر عليه مرتين لتفعيل الركض؛ خطوات الركض أعلى صوتاً.
- المعدن أعلى ضجيجاً، والسجاد أخفت، والزجاج خطر ويُحدث صوت كسر عند دخوله.
- HUD يعرض حالة الحركة، سطح الأرض، حالة Death Angel، ومؤشر أثر الصوت.
- زر السهم يعيد المرحلة.

## الملفات والتشغيل

تحتوي `SignalLast/` على ملفات Swift والموارد. ملف `Project.yml` مهيأ لـ XcodeGen، و`SignalLast.xcodeproj` هو المشروع المحدّث. سير عمل GitHub Actions يبني التطبيق دون توقيع على macOS ويجمع ناتج IPA غير موقع.

لإعادة توليد مشروع Xcode عند توفر XcodeGen: `xcodegen generate`، ثم افتح `SignalLast.xcodeproj` في Xcode. أصوات الخطوات والتنفس الحالية موارد مؤقتة؛ نقاط الربط `AudioManager.play(.deathAngelScreech)` و`AudioManager.play(.deathAngelBreath)` جاهزة لاستبدالها بملفات مرخصة. لم أتحقق من بناء iOS أو التشغيل: بيئة التحرير الحالية لا تتضمن أدوات Xcode أو iOS SDK.
