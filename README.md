# إشارة أخيرة — Phase 1

تنفيذ Phase 1 مهيأ بـ SwiftUI وSpriteKit ويستهدف iOS 17 أو أحدث. يحتوي على غرفة بسيطة ذات جدران، حركة لمس بثلاث سرعات، نظام ضوضاء يتغير بحسب السطح، وDeath Angel بأربع حالات: دورية، تحقيق، اندفاع، وبحث. Death Angel أعمى في هذه المرحلة ولا يتفاعل إلا مع أحداث الضوضاء.

## التحكم

- حرّك العصا الافتراضية اليسرى برفق للتسلل بصمت؛ ادفعها بقوة للمشي وإصدار خطوات مسموعة.
- اضغط مطولاً على زر الركض أو انقر عليه مرتين لتفعيل الركض؛ خطوات الركض أعلى صوتاً.
- المعدن أعلى ضجيجاً، والسجاد أخفت، والزجاج خطر ويُحدث صوت كسر عند دخوله.
- تعرض الواجهة الحركة وسطح الأرض وحالة Death Angel ومؤشر أثر الصوت.
- زر السهم يعيد المرحلة.

## التشغيل والإعداد

افتح `SignalLast.xcodeproj` في Xcode 16 أو أحدث، واختر مخطط `SignalLast` ثم جهاز iPhone أو محاكي iOS 17+. ملف `Project.yml` مهيأ لـ XcodeGen، ويمكن إعادة توليد المشروع باستخدام `xcodegen generate`. يضم مشروع Xcode ملفات Swift وموارد Death Angel والصوت المؤقت فقط؛ لا يُضمَّن Demogorgon في مرحلة اللعب الحالية.

سير عمل GitHub Actions في `.github/workflows/build.yml` يبني التطبيق دون توقيع على macOS ويجمع ناتج IPA غير موقع. أصوات الخطوات والتنفس الحالية موارد مؤقتة؛ نقاط الربط `AudioManager.play(.deathAngelScreech)` و`AudioManager.play(.deathAngelBreath)` جاهزة لاستبدالها بملفات مرخصة. لم أتحقق من بناء iOS أو التشغيل لأن بيئة التحرير لا تتضمن أدوات Xcode أو iOS SDK.

## مؤجل إلى Phase 2

`DemogorgonAI` وصياد الضوء، ونظام الضوء/البطارية، والأغراض والتشتيت، والنهايات، والاختباء، وتحذيرات النبض والـ vignette. لا يوجد تنفيذ لسلوك Demogorgon في Phase 1.
